# 骰子工具功能增强计划

## 概述

为现有的骰子工具增加投掷方式选择（点击投掷/摇一摇投掷）、增强的动画效果和酷炫的特效，默认配置默认1个骰子、d6类型。摇一摇模式配合不透明杯子遮罩，增加音效反馈。

## 技术方案

| 维度 | 选择 | 理由 |
|------|------|------|
| 平台 | mobile | 与现有项目一致，移动端小程序 |
| 动画实现 | CSS Animations + requestAnimationFrame | 性能好，交互流畅 |
| 摇一摇功能 | Taro.onAccelerometerChange | Taro原生加速度传感器API |
| 音效 | Taro.createInnerAudioContext | Taro原生音频API，提供投掷和停止音效 |
| 杯子遮罩 | SVG + CSS动画 | 实现不透明杯子摇晃的视觉效果 |
| 状态管理 | useState + useRef | 简单需求，无需引入额外库 |

## 功能模块

### 1. 投掷方式选择
- **职责**：提供点击投掷和摇一摇投掷两种方式
- **默认**：默认点击投掷
- **UI**：底部设置入口，弹窗选择投掷方式

### 2. 骰子动画
- **职责**：投掷时酷炫的旋转和弹跳动画
- **效果**：
  - 骰子旋转动画（CSS keyframes
  - 3D透视效果
  - 弹跳震动反馈
  - 结果弹出动画

### 3. 摇一摇功能 + 杯子遮罩
- **职责**：监听设备摇动触发投掷，配合杯子遮罩视觉效果
- **实现**：
  - 加速度传感器监听
  - 摇动阈值判断
  - 防止重复触发
  - 不透明杯子SVG图标
  - 杯子摇晃动画（跟随加速度晃动）
  - 摇到一定程度后杯子掀开显示结果

### 4. 音效系统
- **职责**：提供投掷、摇晃、停止等音效反馈
- **实现**：
  - 摇晃音效（循环播放，随摇动强度变化
  - 骰子停止音效（结果出现时
  - 杯子掀开音效（揭开时

### 5. 设置面板
- **职责**：统一管理投掷方式等设置
- **入口**：右上角设置图标
- **内容**：投掷方式选择

## 页面规格

##### @page(/dice) 骰子页面

**核心职责**：提供多种骰子类型选择、数量调整、两种投掷方式（点击/摇一摇）、配合杯子遮罩和音效的酷炫动画效果展示骰子结果。
**访问路径**：首页快捷工具或工具箱直达。
**布局**：
- 顶部：标题栏 + 返回按钮 + 设置图标
- 中段：骰子类型选择、数量调整
- 主区域：杯子遮罩区（摇一摇模式）或骰子展示区（点击模式）
  - 摇一摇模式：显示不透明杯子，跟随设备摇晃
  - 点击模式：显示骰子投掷动画
- 底部：投掷按钮
**列表项字段**：无列表。
**状态**：
- 空态：显示大骰子图标 + "点击下方按钮掷骰或摇一摇"
- 投掷中（点击模式）：显示旋转动画的骰子
- 投掷中（摇一摇模式）：显示摇晃的杯子
- 结果态：显示杯子掀开/骰子最终结果 + 弹跳动画

**交互说明**

| 元素 | 动作 | 响应 | 传参 | 备注 |
|------|------|------|------|------|
| 设置图标 | 点击 | 打开设置面板 | — | — |
| 投掷按钮 | 点击 | 触发投掷动画 | — | — |
| 摇一摇设备 | 摇动 | 触发杯子摇晃动画，达到阈值后投掷 | — | 摇一摇模式下 |

**设置面板 settings-panel**：
- 标题："投掷设置"
- 选项：
  - 投掷方式（单选）：点击投掷 / 摇一摇投掷
- 操作：关闭面板（点击空白区域或关闭按钮）
