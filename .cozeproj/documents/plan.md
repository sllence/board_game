# 计时器增加标记计时功能 — 实施计划

## 概述

在现有计时器（支持倒计时 + 正计时）的基础上，为正计时（秒表）模式增加"标记计时"（Lap/Split）功能。用户可在正计时运行过程中点击按钮记录当前时间点，形成分段时间列表，并支持查看、重置标记记录。数据仅在内存中管理，无需后端和数据库。

## 技术方案

| 维度 | 选择 | 理由 |
|------|------|------|
| 前端框架 | Taro 4 + React 18 | 项目现有技术栈 |
| 样式 | Tailwind CSS + design_guidelines 规范 | 保持与现有设计一致 |
| 状态管理 | 组件内 useState + useRef | 标记数据仅页面内使用，无需全局状态 |
| 数据持久化 | 无（内存存储） | 计时标记为临时数据，无需持久化 |
| 后端 | 无改动 | 纯前端功能 |

## 功能模块

### 标记计时（正计时模式）
- **触发条件**：正计时运行时，显示"标记"按钮
- **记录内容**：每个标记记录 `序号`、`总用时`（从开始到标记时刻）、`分段用时`（与上一个标记的时间差）
- **数据存储**：`LapMark[]` 类型数组，内存管理
- **数据重置**：点击重置按钮时清空所有标记记录
- **列表展示**：在计时器下方滚动展示所有标记记录，最新标记在顶部

### LapMark 数据结构
```typescript
interface LapMark {
  id: number          // 序号（1-based）
  elapsed: number     // 总用时（秒）
  split: number       // 分段用时（秒）
}
```

### 交互说明
- 正计时**运行中**：显示"标记"按钮（绿色渐变），点击记录一条标记
- 正计时**暂停/停止**：隐藏"标记"按钮
- 标记列表：显示序号、分段用时、总用时，最新在前
- 列表为空态：显示"暂无标记记录"提示

## 页面规格

##### @page(/timer) 计时器

**核心职责**：倒计时与正计时，正计时支持分段时间标记
**访问路径**：TabBar 工具箱 → 计时器入口；或首页快捷入口

**布局**：
顶部：标题栏（图标 + 标题）
中部：模式切换（倒计时 / 正计时）
倒计时：快速预设选择 → 圆形时间显示 → 控制按钮（重置、开始/暂停）
正计时：圆形时间显示 → 标记按钮 + 控制按钮（重置、标记、开始/暂停）→ 标记列表

**状态**：
- 空态：正计时未开始时，标记列表为空，显示"暂无标记记录"
- 运行态：显示标记按钮，可连续记录标记
- 暂停态：标记按钮隐藏

**交互说明**

| 元素 | 动作 | 响应 | 备注 |
|------|------|------|------|
| 标记按钮 | 点击 | 记录当前时间点，添加到列表顶部 | 仅正计时运行时显示 |
| 重置按钮 | 点击 | 停止计时，重置时间，清空所有标记 | 正计时模式下同时清除标记列表 |
| 标记列表项 | — | 展示序号、分段用时、总用时 | 最新在前，滚动查看 |
