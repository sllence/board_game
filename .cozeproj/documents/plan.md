# 计划：调整对局页面快捷工具

## 概述

调整对局进行页（`pages/navigator/index`）底部的快捷工具栏，从现有的 5 个工具（骰子、计时、抽牌、选人、计分）精简为 3 个（选人、骰子、计时），按指定顺序排列。这是一个纯逻辑层面的配置修改，不涉及 UI 重设计或新增功能。

## 技术方案

| 维度 | 选择 | 理由 |
|------|------|------|
| 修改范围 | 仅修改 `TOOL_ITEMS` 常量数组 | 快捷工具列表由该数组驱动，修改它即可实现增删和排序 |
| 影响面 | 仅 `src/pages/navigator/index.tsx` | 无其他页面或后端依赖 |

## 功能模块

### 快捷工具列表调整

- **原数组**：`dice`（骰子）、`timer`（计时）、`cards`（抽牌）、`finger`（选人）、`scorer`（计分）
- **新数组**：`finger`（选人）、`dice`（骰子）、`timer`（计时）
- **删除项**：`cards`（抽牌）、`scorer`（计分）

## 是否有原型设计

是（工具开关已开启，但本次为纯逻辑修改，无 UI 变更，原型阶段只需确认无需额外设计）

## 实施步骤

1. **阶段一：原型确认** — 加载 design-canvas 技能，确认现有对局页面原型与本次修改无冲突；用户确认后进入开发阶段
2. **修改 `TOOL_ITEMS` 数组** — 在 `src/pages/navigator/index.tsx` 中将 `TOOL_ITEMS` 缩减为选人、骰子、计时三项，按 finger → dice → timer 顺序排列
3. **执行 `pnpm validate` 校验** — 确保 TypeScript 和 ESLint 通过，无未使用变量等问题
4. **编译检查** — 执行 `pnpm build` 确认构建正常

## 页面规格

本次不涉及页面规格变更。
